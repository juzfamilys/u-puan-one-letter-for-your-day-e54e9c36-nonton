## The letter

**Z** — for **"zero sleep"** (also zonked / zombie): a vivid, funny, true picture of a long day with no sleep. The entry file contains exactly that one letter, nothing else.

## Run it

```sh
python3 main.py
```

This writes the single letter `Z` (exactly 1 byte, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), then reads the file back and re-validates it.
